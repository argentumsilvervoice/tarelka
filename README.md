# Гарвардская тарелка

Визуальный AI-конструктор сбалансированной тарелки на русском языке.

## Что внутри

- Однофайловое HTML/CSS/JS приложение без backend.
- Встроенная база продуктов.
- Онбординг, демо-профили и три режима работы.
- Визуальная тарелка, качественные рекомендации и мягкий wellness-ТКМ слой.
- Без подсчёта калорий как основного сценария.

## Запуск

Откройте `index.html` в браузере или разместите файл на GitHub Pages / Timeweb.

## НутриАссистент (новая версия)

`nutriassistant.html` — отдельное приложение «НутриАссистент: семейный конструктор
здорового питания». Понимает, что уже есть дома, учитывает предпочтения каждого
члена семьи и собирает план питания и список покупок. Четыре вкладки: «Дома», «План»,
«Семья», «Покупки». Однофайловое HTML/CSS/JS без backend, всё состояние — в памяти.
Откройте `nutriassistant.html` в браузере. Прежняя версия (`index.html`) сохранена без изменений.
